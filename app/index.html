🏁 Inicializar

git start

Inicializa un proyecto desde cero en la rama main, realiza el commit inicial y vincula al servidor remoto si se proporciona una URL.

git start "Estructura inicial" https://github.com/user/repo.git
🛡️ Snapshot

git backup

Crea un snapshot de seguridad inmediato con sello de fecha y hora. Guarda cambios pendientes y genera tag automático.

git backup
🚀 Release

git release

Genera una versión estable auto-incrementada (ej. v2026.07.24 o v2026.07.24.1) y la sube al repositorio remoto.

git release "Versión 1.0 lista"
⏪ Rollback

git rollback

Vuelve al último backup o release disponible. Si se indica un tag específico, restaura exactamente a ese punto.

git rollback
⏪ Rollback Release

git rollback-release

Vuelve exclusivamente al último release estable, ignorando los backups temporales intermedios.

git rollback-release

⚙️ Instalación Rápida por Consola

Copia el comando de instalación correspondiente a tu sistema:

🪟 Windows (Doble Click / CMD)

install.bat TU_USUARIO_GITHUB

💙 Windows PowerShell

.\install.ps1 -GitHubOwner TU_USUARIO_GITHUB

🐧 Git Bash / Linux / macOS / Termux

sh install.sh TU_USUARIO_GITHUB

📱 Uso en Celulares Android (Termux)

  1. Instalá Termux desde F-Droid.
  2. Instalá Git en Termux:
    pkg install git -y
  3. Cloná el repositorio o instalá los alias ejecutando:
    git clone https://github.com/nippurx/git-tools.git && cd git-tools && sh install.sh
  4. ¡Listo! Ya podés usar git start, git backup y git release desde tu celular.

📲 Cómo Instalar esta PWA en tu Celular

  • Android (Chrome / Edge): Toca el botón "Instalar App" en la parte superior o en el menú de Chrome selecciona "Agregar a la pantalla de inicio".
  • iPhone / iPad (Safari): Toca el botón Compartir 📤 y luego selecciona "Agregar a la pantalla de inicio" ➕.
